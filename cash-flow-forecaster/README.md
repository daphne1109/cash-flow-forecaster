# Cashflow

Cashflow is a local-first prototype that helps a student or early-career worker
turn rough answers about income, groceries, transport, bills, and subscriptions
into an editable 30-day cash forecast.

## Current milestone

Project foundation and the first pure domain contract are complete: React,
TypeScript, Vite, Vitest, and a production-build check are configured. The
domain layer defines validated forecast items and settings; recurrence
expansion, forecast calculation, and guided setup are not yet built.

## Run locally

```bash
npm install
npm run dev
```

## Verify

```bash
npm test
npm run build
```
